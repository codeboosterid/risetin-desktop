# Risetin Desktop

Unduhan resmi **Risetin Desktop** — pendamping penulisan naskah jurnal Scopus Q1
dari data riset Anda sendiri. Berkas riset dibaca langsung dari komputer Anda
dan tidak diunggah ke server.

Repo ini hanya berisi rilis aplikasi. Situs dan akun: **https://risetin.id**

## Pasang di Linux (64-bit)

```bash
curl -fsSL https://risetin.id/install.sh | bash
```

Atau unduh `Risetin-x.y.z-x86_64.AppImage` dari halaman
[Releases](https://github.com/codeboosterid/risetin-desktop/releases/latest),
lalu jalankan:

```bash
chmod +x Risetin-*.AppImage && ./Risetin-*.AppImage
```

AppImage membutuhkan FUSE 2 (Ubuntu/Debian: `libfuse2`, Fedora: `fuse-libs`,
Arch/CachyOS: `fuse2`). Windows dan macOS menyusul.

## Mulai

1. Buka Risetin, klik **Masuk** atau **Daftar akun baru**.
2. Beli paket naskah di portal https://risetin.id.
3. Pilih folder riset Anda dan mulai bertanya.

Bantuan: support@risetin.id
